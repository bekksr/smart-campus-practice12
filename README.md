# Smart Campus — Practice 12

## Project Overview
Smart Campus Room Availability Checker.

This project compares two approaches to implementing
a room availability checking system:

1. Code-based implementation — React, TypeScript and Vite.
2. Low-code implementation — to be developed using Appsmith.

## Project Structure

- code-based/ — React application.
- low-code/ — Low-code implementation.
- docs/practice12/ — Shared requirements and test cases.
- evidence/practice12/ — Test results and screenshots.
- report/ — Final practice report.
