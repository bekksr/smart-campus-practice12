# Smart Campus Room Availability Checker

Software Engineering Practice #09 and #10.

## Project overview

A room availability checker built with React, TypeScript and Vite.

The application checks room availability against existing fictional bookings.

## Main features

- Room availability validation
- Booking conflict detection
- Blocked-room validation
- Input and time validation
- Responsive user interface

## Technology stack

- React
- TypeScript
- Vite
- Vitest

## Development

Install dependencies:

npm install

Run development server:

npm run dev

Run tests:

npm test

Build:

npm run build
